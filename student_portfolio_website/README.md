# Student Portfolio Website

A responsive student portfolio made with plain HTML and CSS, following the supplied student portfolio guide.

## Files
- `index.html` — portfolio sections and content
- `style.css` — layout, colors, responsive styling
- `images/profile.jpg` — optional profile photo (add your own image here)

## Customize before submitting
1. Replace `Your Name`, `YN`, the introduction, about text, and skill levels with accurate information.
2. Add your own photo at `images/profile.jpg` (or change the image path in `index.html`).
3. Replace all sample project cards with your real class/practice projects, screenshots, explanations, your contribution, and working links.
4. Replace `your.email@example.com` and `yourusername` with your real public contact links.
5. Test all links and the mobile menu. The email link opens the visitor's configured email application; it is not a contact form.
6. Do not publish passwords, private documents, or other sensitive information.

## Preview locally
Open `index.html` in your browser, or open the folder in VS Code and use Microsoft's Live Preview extension.

## Publish with GitHub Pages
1. Create a public GitHub repository named `portfolio`.
2. Upload the *contents* of this folder (including `index.html`, `style.css`, and `images/`) to the repository root.
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. After publishing finishes, open the public HTTPS link shown in Pages and test it in an incognito window and on a phone.

This is a static HTML/CSS website and does not require a build step.
